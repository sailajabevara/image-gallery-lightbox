# Light Table – Image Gallery & Lightbox

A simple responsive image gallery built using HTML, CSS, and JavaScript. The gallery displays images fetched from the Picsum API and allows users to view them in a lightbox with navigation controls.

## Features

- Responsive image gallery layout
- Images loaded dynamically from Picsum API
- Lightbox view for larger image display
- Previous and Next image navigation
- Keyboard support (Arrow Keys and Escape)
- Loading and error handling
- Mobile-friendly design
- Accessible user interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Picsum API

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Run the application using a local server.

Example:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

You can also directly open the `index.html` file in a browser.
